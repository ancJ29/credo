# The UI's shape, recap, 2026-11-10

Written after the piece reached `main` (merge `65217a1f`), not before its squash.

## What happened

The customer and the product each had a record page and an add screen: four screens, two bodies written twice. The piece draws them with one body each, `ui/src/pages/client/RecordPage.tsx` and `ui/src/pages/client/AddRecordPage.tsx`, with the kind as data. It also built the three parts the code convention (C3) says must exist before any client's own page can be anything but a copy: `ui/src/parts/PageShell.tsx`, `ui/src/parts/ListTable.tsx`, and the list kind as the entry point (`ListKind` is `keyof typeof LISTS`, and `ui/src/ClientApp.tsx` maps its routes over it). A refusal now returns its kind, so five screens stop deciding it twice. The two forms moved to `ui/src/parts/` byte for byte, since the kinds differ for real there.

**The promise was that no screen moves, and the proof was a picture run, not an argument.** `walk/run.sh admin-lists piece-2` at the merge commit: 6 comparisons, every one 0 moved. Lists walk 126 pictures, staff walk 204, each compared fake to stack, stack to stack, and stack to the committed bases. The third comparison is the one that would show this piece moving a screen.

## What the next session would otherwise re-learn

- **Prove an extraction by bytes.** The review cut each form's region out of the old tree and the new and compared them: 121 lines (customer) and 175 lines (product), identical. That one measurement settled every difference the plan had named between the kinds (the product form's `noValidate`, its own fields, the blank price box, the two note merges). Re-derived here: both regions sit unchanged inside `CustomerForm.tsx` and `ProductForm.tsx`.
- **A test that reads a file's source text goes quiet when its subject leaves the file.** The case "none a bordered paper" in `ui/src/pages/client/ListPage.test.tsx` read `ProductPage.tsx`; once the page's body moved, that file was a three-line shim and the case passed while checking nothing. No gate saw it; the coordinator caught it at step 6c, by reading. The case now reads both files its subject spans, and each was shown red with a `withBorder` added. The review then swept for others: only two files in `ui/src` call `readFileSync`, and the other reads a stylesheet this piece did not touch. A renamed file now throws instead of passing.
- **The deletions left the live damage, and the open log is outside the citation check.** Three live open items (105, 146, 147) cited the deleted page files by line; `docs/open-items.md` is not in the check's living set (`scripts/src/citations.ts`'s `LIVING`), so "0 red citations" was true and blind. Four live places also named `isForbidden` as the reachable home after step 3 made it private (knip refused the export); that one is blind for a different reason, since `countHomes` in `scripts/src/counts.ts` only asks the home be declared once. Both fixed in `129e1a7d`. After a deletion or an unexport, grep the whole tree, open log included.
- **A review's claim is a claim.** The review called the menu a fourth tie to the kinds; the fix pass tried it and it is not: a menu entry's id is a plain string, so a kind with no menu entry is not a type error. The convention now names the dictionary words, which are, and leaves the menu out.

## What it cost, and what remains

- **Rejected:** a new test suite; `ListPage.test.tsx` (42 cases) stayed unedited apart from the one re-pointed case. Also rejected: converting the other 30 hand-written page headings, each a screen the picture run must re-judge for no gain.
- **Left open, item 207:** the pairing of each kind with its spec is by hand, so `products` built with the customer spec typechecks and draws the wrong words. The convention's "a type error and not a screen that silently draws the wrong one" holds for a missing kind, not a mis-paired one. Trigger: the third kind, or the first edit to either record page.
- **Still true beyond this piece:** two ternaries in `ui/src/listSheet.ts` read a third kind as a product.
- **Not deployed**; no look was needed beyond the run, whose criterion (green, every count 0) was written before it.
