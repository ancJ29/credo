# The local copy, recap, 2026-11-10

Written after the piece reached `main` (branch merged at `b79c84c2`, its quick-start page at `0c938a52`), not before its squash.

## What happened

The app, its data and a demo company already stood up on one Mac, but only inside one command: `pnpm stack` built, started and erased everything in one call, so nothing was left to return to or add a company to. The piece gave it a lifetime the shell outlives. `pnpm local up` leaves it standing on fixed ports (front 3180, storage 3181) and prints the demo company's link and the root's password; `status` reads each part's own answer; `seed <code> [<name>]` adds another company with the demo set's records; `stop` turns it off and keeps the data, which the next `up` resumes; `down` deletes it all. Five commands, where the ask said three: `stop` came later, to keep the data between sittings.

**It was walked, not argued.** The human ran the commands in their own terminal and said at 16:13 that stop and resume were "as expected". `down` is proved by what it reads back afterwards (the three processes, the four ports, the data and build folders, the handle), never by its own exit code.

## What was rejected, and at what price

- **Children that outlive the command** (the plan's first idea): the front and the seed door are servers inside the starting process, so only storage and the server would have stayed. A *keeper* process now holds all four parts (`46deddcb`).
- **A copy of the shared environment's scripts**: the seed takes its target from the environment, as that environment's own command does, so it can run the same path later. Cost: its `seed` line in `ops/seed.sh` is still unwritten.
- **A seed that matches an existing company**: a second seed of one code is refused, exit 2 (`f01a32e1`); matching means reconciling a week of orders.
- **The teardown's planned read-back through `classifyProcesses`, and of `credo-stack-*` folders**: dropped; it would count other runs' processes, and this stack never makes such folders (`3ba1a094`).

## What remains the human's

Seeding on the shared environment, and whether that wiring is wanted next. Four small findings from the review sit open in the open log (`98828113`). The stop's output says "was not running" for storage and the server, which the keeper had already ended; correct, but worded as if they died earlier, to be filed.
