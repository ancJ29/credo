# For the operator

This page is for the person who keeps credo running. Today that is us, the owner. After it you know where to start, what you can do without typing commands, and whom to ask.

**Start here: [what the operator does in the operator console](operator-console.md).** Every task an operator does in the [operator console](words.md#operator-console) is there. You can add a client, give a client a new password, and move or delete a client. You can add or remove operators and see whether the services answer. Read it first because you need no commands for any of it.

**Behind it, only if we send you:** [the operator guide](../operator-guide.md) lists every task, including those that need a typed command, and [the runbook](../../ops/README.md) says why each step is done. Both are for someone who works in a terminal, a window where you type commands. We do that work today, so you do not need them to run the console.

**Whom to ask:** us, for anything the console page does not answer. Your question and our answer go on [the questions page](questions.md), so the next person finds it.
