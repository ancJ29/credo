# For a new developer

This page is for someone joining the code. After it you know which five pages to read, and in what order. Each page lets you do one more thing. You set up your machine and run your own copy of the app. You follow one click to a saved record. You write a change the way this project asks, and you know what counts as done.

1. **[First-time setup](../first-time-setup.md).** Install the tools, get the code and run the app once. You finish with a machine that can build and start credo.
2. **[Quick start](../quick-start.md).** Run your own copy of the app with an invented company in it. You finish able to start it, stop it and clear it away.
3. **[How credo is built](../architecture.md).** Follow one change to a customer's phone number from the screen to the saved record. You finish knowing which part makes which decision.
4. **[The code rules](../conventions/code.md).** Where a new file goes, and the one way to write each job. Read it before you add or change any code.
5. **[How we check our work](../conventions/qa.md).** What is checked, when, and what counts as done. Read it before you run a check or hand in a change.

You know it worked when your own copy runs and you can say which part owns a given rule. If you do not know what your first change should be, ask us. The answer goes on [the questions page](questions.md).
