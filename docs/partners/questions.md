# Questions and answers

This page is for any partner with a question. After it you know whether someone has asked it before, and how to ask it yourself.

## How to ask

Send your question to us. We answer it here, so the next partner who wonders the same thing finds the answer without asking.

## What an entry holds

Each entry has the question as its heading, so you can scan for yours. Under it are the date, and who asked, as a label such as p1 and never a name, so no partner's name spreads. Then comes the answer in plain words. Last is the page the answer changed, if any, with a link. An answer that changes a page changes that page itself, so the page stays true.
